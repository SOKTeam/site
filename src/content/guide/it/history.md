S.O.K ricorda le Sue ultime 100 rinomine. Ognuna può essere annullata, tutta insieme o file per file.

## Subito dopo una rinomina

Il messaggio mostrato alla fine di una rinomina ha un pulsante **Annulla la rinominazione**. Lo clicchi e i file tornano nella loro cartella con il nome precedente. Nelle pagine *Film*, *Libri*, *Giochi* e *Brani* tornano anche nella tabella, così può scegliere un altro risultato e rinominarli di nuovo.

## La pagina Cronologia

Apra **Cronologia** nella barra laterale, sopra *Impostazioni* (su Mac anche con **Vista → Cronologia** o <kbd>Cmd</kbd>+<kbd>Y</kbd>). Ogni rinomina è una scheda con la pagina in cui è stata fatta, il numero di file e la data.

- **Annulla** rimette a posto tutti i file della rinomina, dopo una conferma.
- Clicchi sulla scheda per vedere i suoi file, nome precedente → nuovo nome. Il pulsante **↺** accanto a un file rimette a posto solo quel file.
- Una rinomina annullata è segnata come *Annullato*, o *Annullato in parte* quando sono tornati solo alcuni dei suoi file.
- **Svuota la cronologia** dimentica tutte le rinomine, dopo una conferma. I file restano dove sono, ma le rinomine non si possono più annullare.

## Cosa fa l'annullamento

- Ogni file torna nella sua cartella precedente, con il nome precedente. I suoi sottotitoli tornano con lui.
- Un file rinominato con un **collegamento fisico** o una **copia** viene eliminato, se l'originale è ancora lì: l'originale non si è mai mosso.
- Se una rinomina ha sostituito un file e *Backup prima della rinomina* era attivo, il file sostituito viene rimesso a posto.
- I poster e le copertine salvati dalla rinomina vengono eliminati quando tutti i loro file sono tornati. Le immagini già presenti non vengono mai toccate.
- Le cartelle create dalla rinomina vengono eliminate quando restano vuote.

L'annullamento **non sostituisce mai un file**. Un file resta dov'è, e compare nel messaggio con il motivo, quando:

- è stato **spostato o eliminato** dopo la rinomina;
- **un altro file ha il suo nome precedente** nella cartella precedente.

Sposti o rinomini Lei quel file, poi clicchi di nuovo su **Annulla**: i file già tornati vengono saltati.

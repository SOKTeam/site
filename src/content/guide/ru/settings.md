Откройте **Настройки** внизу боковой панели. Каждое изменение сохраняется сразу: кнопки *Сохранить* нет.

## API ключи

S.O.K получает сведения из онлайн-баз данных. Этот раздел перечисляет их по категориям (видео, музыка, книги, игры, изображения) вместе с их статусом.

| Тип | Сервисы | Что нужно сделать |
| --- | --- | --- |
| **Встроенный ключ** | TMDB, TVDB, Fanart.tv | Ничего. Ключ уже есть. Свой ключ можно ввести в поле *Свой ключ (Опционально)*. |
| **Бесплатно** | Deezer, MusicBrainz, Google Books, Open Library, RAWG | Ничего. |
| **Подключение** | Spotify, IGDB | Нажмите **Подключить** и выполните шаги. |
| **Личный ключ** | OMDb (IMDb), Last.fm | Создайте бесплатный ключ на сайте сервиса и вставьте его. |

### Добавление личного ключа

1. Нажмите **Получить** рядом с сервисом. S.O.K откроет страницу, где можно создать ключ.
2. Скопируйте ключ и вставьте его в поле. Он сохраняется при нажатии <kbd>Enter</kbd> или при выходе из поля; очистите поле, чтобы удалить ключ.
3. Нажмите **Тест**. Статус сменится на *Работает*, если ключ подходит, или на *Неверный ключ*, если нет.

### Подключение учётной записи

1. Нажмите **Подключить** рядом со Spotify или IGDB.
2. S.O.K запросит API ключ (и секрет, если сервису он нужен) и может открыть страницу сервиса, чтобы его создать.
3. При успехе статус сменится на *Подключено*.

Чтобы удалить подключение, нажмите **Отключить**.

> Ваши ключи хранятся на компьютере в зашифрованном виде.

## Предпочитаемый API

Для каждой категории выберите, какую базу данных S.O.K использует первой. Если выбранному сервису всё ещё нужен ключ, появится предупреждение ⚠️.

## Папки по умолчанию

Запоминает папку каждой из ваших библиотек (видео, музыка, книги, игры). Нажмите **Обзор**, чтобы выбрать папку.

Когда страница открывается с пустым полем *Назначение*, S.O.K подставляет папку по умолчанию для этого типа медиа. Выбрать другую папку всё равно можно.

## Форматы вывода

Определяют, как переименовываются файлы. Введите в поле новый шаблон. Слова в фигурных скобках заменяются сведениями о медиа.

| Медиа | Формат по умолчанию | Доступные переменные |
| --- | --- | --- |
| **Сериал** | `{title} S{season}E{episode} {episode_title}` | `{title}`, `{season}`, `{episode}`, `{episode_title}` |
| **Фильмы** | `{title} ({year})` | `{title}`, `{year}`, `{quality}` |
| **Музыка** | `{artist} - {album}/{track} - {title}` | `{artist}`, `{album}`, `{track}`, `{title}`, `{year}` |
| **Книга** | `{author} - {title} ({year})` | `{author}`, `{title}`, `{year}`, `{series}`, `{series_number}` |
| **Игра** | `{title} {tags}` | `{title}`, `{year}`, `{platform}`, `{tags}` |

**Примеры:**

- `{title} - S{season}E{episode} - {episode_title}` даёт `Во все тяжкие - S01E01 - Пилот.mkv`
- `{title} ({year}) [{quality}]` даёт `Начало (2010) [1080p].mkv`
- `{artist}/{year} - {album}/{track}. {title}` даёт `Daft Punk/2001 - Discovery/01. One More Time.mp3`

В формате музыки каждый символ `/` создаёт папку. Значение, которого у файла нет, опускается вместе с окружающими его символами: без года `{title} ({year})` даёт `Название`. `{series}` и `{series_number}` берутся из исходного имени книги (`Автор - [Dune 2] - Название`). `{tags}` — это теги из исходного имени игры, например `(USA) (Rev 1)`.

Символы, запрещённые Windows в именах файлов (`< > : " / \ | ? *`), удаляются.

## Форматы ввода

Описывают, как называются **ваши** файлы, чтобы S.O.K читал незнакомые ему имена. Используйте переменные форматов вывода:

1. Выберите тип (Сериал, Фильмы, Музыка, Книга, Игра).
2. Введите шаблон, например `{artist} - {year} - {album} - {track} - {title}`, и нажмите **Добавить**.
3. Проверьте его кнопкой **Проверить**: вставьте имя файла с расширением, и S.O.K покажет, что он прочитал и какой шаблон использовал.

Ваши шаблоны проверяются раньше вариантов, которые S.O.K уже знает. Наведите указатель на **ⓘ** рядом с заголовком, чтобы увидеть эти варианты и переменные каждого типа.

- Пробелы, точки и подчёркивания считаются одним разделителем: `{title} {year}` читает и `The.Matrix.1999`.
- `{ignore}` пропускает часть имени, например качество или релиз-группу: `{title} {year} {ignore}` читает `Dune.2021.1080p.BluRay-GROUP`.
- `{year}` принимает четыре цифры, а номера сезона, серии, трека и диска принимают цифры.
- Шаблону сериала нужен `{episode}`, остальным нужен `{title}`.

Видео, прочитанное шаблоном сериала, считается на главной странице серией, а прочитанное шаблоном «Фильмы» — фильмом.

## Внешний вид

- **Темная тема**: переключает между тёмной и оранжевой темой.
- **Как в системе** (только macOS): следует светлому или тёмному режиму, выбранному в настройках macOS.
- **Использовать системный цвет акцента** (только macOS): использует цвет акцента, выбранный в *Системные настройки → Оформление*.
- **Язык**: English, Français, Deutsch, Español, Italiano, Português, Русский, Polski. Язык также задаёт слова в именах папок (*Season*, *Saison*, *Сезон*...).

## Поведение

| Параметр | Действие |
| --- | --- |
| **Режим файлов** | **Перемещать** (по умолчанию): файлы покидают исходную папку. **Жёсткая ссылка**: оригинал остаётся на месте, поэтому торренты продолжают раздаваться, без лишнего места на диске; папка назначения должна быть на том же диске. **Копировать**: оригинал остаётся, а копия занимает место повторно. |
| **Перемещать субтитры вместе с видео** | Субтитры с тем же именем, что и видео (`Фильм.srt`, `Фильм.ru.srt`, `Фильм.en.forced.srt`), переименовываются и перемещаются вместе с ним: `Дюна (2021).ru.srt`. Включено по умолчанию. |
| **Создавать недостающие папки** | Создаёт папки сериала и сезона в папке назначения, если их нет. |
| **Скачивать постеры** | После переименования сохраняет постер или обложку каждого элемента туда, где их ищут Plex, Jellyfin и Kodi: `Фильм (Год)-poster.jpg` рядом с фильмом, `poster.jpg` в папке сериала, `cover.jpg` в папке альбома или книги. Уже имеющееся изображение сохраняется. Для игр изображения не скачиваются. По умолчанию выключено. |
| **Резервная копия перед переименованием** | Если в папке назначения уже есть файл с тем же именем, перед заменой сохраняет его копию с расширением `.backup`. |
| **Пропускать дубликаты** | Если в папке назначения уже есть файл с тем же именем, исходный файл остаётся на месте вместо замены. |
| **Логировать операции** | Записывает каждое перемещение в файл журнала. |

## О программе

- **Версия**: используемая вами версия.
- **Проверить обновления**: при запуске S.O.K сообщает о новой версии. В Linux он может заменить AppImage новой версией и перезапуститься.
- **Discord Rich Presence**: показывает в вашем профиле Discord, чем вы заняты в S.O.K.
- **Сбросить настройки**: после подтверждения возвращает все настройки к значениям по умолчанию.

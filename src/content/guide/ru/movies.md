Страница **Фильмы** переименовывает целую пачку фильмов за раз. В отличие от сериалов, каждому файлу подбирается свой фильм.

**Поддерживаемые форматы:** `.mkv`, `.mp4`, `.avi`, `.mov`, `.wmv`, `.flv`, `.webm`, `.m4v`, `.mpg`, `.mpeg`, `.3gp`, `.ogv`, `.ts`, `.m2ts`

## Шаг за шагом

### 1. Добавьте фильмы

Перетащите видеофайлы или папки на **Исходные файлы** или нажмите на эту область, чтобы выбрать файлы. S.O.K ищет видео в перетащенных папках, включая вложенные. Позже можно добавить ещё с помощью **+ Добавить ещё фильмы**.

Затем S.O.K сам ищет каждый файл по его имени.

### 2. Проверьте каждое совпадение

У каждого файла есть строка с:

- **текстом поиска**, который можно изменить (название и год, если он известен);
- **списком совпадений**, найденных в базе данных;
- **статусом**.

| Статус | Значение | Что делать |
| --- | --- | --- |
| ✓ **Готово** | У одного совпадения есть название файла и, если файл его указывает, год. | Ничего. |
| ⚠ **Выберите** | Совпадения найдены, но точно не подходит ни одно или подходят несколько. Выбрано наиболее вероятное. | Откройте список и выберите нужный фильм. |
| ✗ **Отсутствует** | Совпадений не найдено. | Исправьте текст поиска и нажмите кнопку повторного поиска в строке. |

> **Совет:** год в тексте поиска (например, `Dune 2021`) помогает избежать большинства путаниц между ремейками.

**Повторить всё** заново запускает поиск для всех файлов.

### 3. Выберите папку назначения

Перетащите папку на **Назначение** или нажмите на эту область, чтобы выбрать её.

### 4. Переименуйте

Нажмите **Переименовать всё** и подтвердите. Переименовываются только строки *Готово*: строки, где нужно сделать выбор, остаются в таблице, чтобы их можно было доделать. Файлы со статусом *Отсутствует* остаются на месте.

В итоговом сообщении есть кнопка **Отменить переименование**. Тогда переименованные файлы возвращаются в свою папку и в таблицу.

## Результат

С форматом по умолчанию каждый файл получает имя `Название (Год)` и перемещается в папку назначения:

```text
Фильмы/
├── Дюна (2021).mkv
├── Матрица (1999).mkv
└── Начало (2010).mp4
```

Формат меняется в разделе [Настройки → Форматы вывода](/ru/guide/settings#форматы-вывода), например чтобы добавить качество с помощью `{quality}`.
